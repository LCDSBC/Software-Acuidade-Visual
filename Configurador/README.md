# Configurador

Modulo independente de calibracao.

No empacotamento Windows, este modulo deve ser aberto como `Configurador.exe` ou pelo atalho
`CTRL+ALT+C` dentro do software principal.

Funcoes implementadas:

- Calibracao de tela por polegadas, resolucao e dimensoes fisicas.
- Calibracao de distancia de 1 a 20 metros, salva em milimetros.
- Regua virtual com fator de escala.
- Inversao horizontal, vertical e rotacao.
- Modo tela unica, duas telas e espelhamento.
- Perfis `.ini`.
- Backup `BackupCalibracao.opt`.
