# Modulo Optotipos

Este e o modulo principal de apresentacao dos testes visuais.

Comportamento esperado:

- Carrega automaticamente `Configuracoes/*.txt`.
- Aplica distancia, escala, perfil, inversao e modo de exibicao.
- Entra em tela cheia quando `TelaCheia=ON`.
- Nao solicita recalibracao ao abrir.
- Abre o configurador com o botao `Configuracoes Avancadas` ou `Ctrl + Alt + C`.

Para gerar o executavel Windows, execute `build_windows.bat` dentro desta pasta.
